# homebrew-tap

Homebrew formulae for Ronni Chidekel's command line tools.

```bash
brew install ronnidc/tap/<formula>
```

| Formula  | What it installs                                                                        |
|----------|-----------------------------------------------------------------------------------------|
| `djdojo` | Downloads a YouTube playlist as lossless AIFF or FLAC for DJ practice. [Source](https://github.com/ronnidc/djdojo) |

Each formula points at a tagged release of its tool. The tool's release workflow updates the URL and checksum here when a `vX.Y.Z` tag is pushed, so this repository is not edited by hand except to add a formula.
